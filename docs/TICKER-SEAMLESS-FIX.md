# Ticker Seamless Fix — ООО «Теплоэнергокомплект»

Дата: 2026-10-27  
Коммит (ожидаемый): `fix(ui): eliminate services ticker gaps`  
Итог QA: **PASS** (375 / 768 / 1440 / 1920 / 2560)

---

## 1. Точная первоначальная причина обрыва

Бегущая строка строилась как **две копии одной 6-пунктной последовательности** и анимировалась через `translateX(-50%)`.

После метрик шрифта Oswald ширина **одной** последовательности (~900–1015 px) **меньше** ширины контейнера на desktop (1440–2560 px).

Следствие:

- дистанция анимации ≈ ширина одной последовательности;
- в любой момент в кадре видно не больше ~одной последовательности + обрезок;
- справа остаётся незаполненная полоса (~30–47% ширины на 1920 px — визуально «обрыв на ~70%»).

`animation: linear infinite` сама по себе **не устраняет** пустоту: бесшовность возможна только если **каждая** из двух идентичных групп шире или равна видимому контейнеру. Иначе `-50%` сдвигает короткий блок по широкому окну и зритель видит фон `.marquee`.

Предыдущая попытка с `ResizeObserver` была концептуально верной, но недостаточно строгой:

- не гарантировала пересчёт после `document.fonts.ready` / поздней смены метрик;
- опиралась на `%`-сдвиг без явной пиксельной дистанции = ширине группы;
- QA мог «зеленеть» на кадре середины цикла, когда вторая копия уже заехала в кадр.

## 3. Новая реализация

Файлы:

- `src/components/sections/home/ServiceTicker.tsx`
- `src/app/globals.css` (блок `.marquee*`)

Принцип:

1. Базовая последовательность = `services.map(s => s.shortTitle)` (6 направлений, без «Обслуживание»).
2. Off-screen probe `.marquee-measure` измеряет фактическую ширину последовательности.
3. `cycles = ceil(containerWidth / sequenceWidth)` (с потолком), пока `groupWidth ≥ containerWidth`.
4. На треке ровно **две** одинаковые группы подряд, `gap: 0`, `justify-content: flex-start`, `flex-shrink: 0`.
5. Анимация CSS `linear infinite` на пиксельную дистанцию `--marquee-shift: -<groupWidth>px` (эквивалент `-50%` при двух равных группах, но без двусмысленности бокса).
6. `ResizeObserver` на контейнер и probe; дополнительно `document.fonts.ready` + `loadingdone`.
7. `prefers-reduced-motion` → статичный ряд без анимации.
8. Дубликат группы с `aria-hidden`.

Почему это **математически** исключает пустоту:

- в любой момент `t` видимое окно `[x, x+W]` лежит внутри объединения двух групп длины `G` при `G ≥ W` и сдвиге по модулю `G`;
- при `translate ≡ 0` и `translate ≡ -G` картинка совпадает (группы идентичны) → бесшовный стык цикла.
