4. **Как проверить документы** — ссылки на соответствующие реестры НАКС.
5. **Контроль качества и аттестация** — пять компактных пунктов без обещания «всех разрешений на любые работы».

Кнопка «Скачать документ» **не показывается** (файлы не одобрены).  
Бейджи «Действует» / «Проверено» как статус действия документа **не используются**; для карточек применяется нейтральный статус сверки сведений.
